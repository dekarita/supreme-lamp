## A. Method (reproducible)

1. A temporary TypeScript-compiler-API indexer (kept outside the repository on purpose; it is research tooling, not
   the WP-03B generator) parsed every `src/**/*.ts(x)` file except `src/tests/**`, `**/fixtures/**` and `*.d.ts`
   (168 files).
2. A **JSX control site** is any JSX element that (a) is a native interactive tag (`button`, `a` with `href` or a
   handler, `input`, `select`, `textarea`, `form`, `summary`), (b) is a shared control primitive (`Button`,
   `IconButton`, `CopyButton`, `CopyLink`, `Toggle`, `Tabs`, `MaskedField`, `DataTable`, `Drawer`, `Modal`,
   `NavLink`), (c) has an interactive `role`, or (d) carries any `on*` prop.
3. Sites are split into **primitive-internal** (inside `src/components/primitives/*`, the forwarding layer) and
   **call-sites**; call-sites are split into **DOM controls**, **component-callback props** (an `on*` prop handed to
   a non-primitive component — wiring, not a control) and **media/lifecycle handlers**.
4. For every site the indexer recorded: file/line, enclosing component, tag, `data-testid`/`id`/`aria-label`,
   `type`, `disabled` expression, handler prop names and text, enclosing `.map()` receiver (dynamic family),
   enclosing render conditions, explicit `logButtonAction`/`instrumentButton` use at the call-site (or in a
   same-file named handler), file-level import reachability to a registry feature or chrome root, and the test files
   that contain the literal testid (or derived prefix).
5. Global-capture eligibility is evaluated statically against `CLICKABLE` and `GLOBAL_CLICK_IGNORE` in
   `src/lib/globalClickCapture.ts`.
6. Cross-check: the same population restricted to F-TESTID's five tags gives **206** sites; F-TESTID's own scanner
   (executed unmodified apart from its `test()` harness) gives **204**. The two missing sites are explained in §C.4.

**Definitions and exclusions.** *Static site* = one JSX element in source. *Reusable primitive* = a component in
`src/components/primitives/` whose internal DOM controls are counted once (27 primitive-internal sites). *Dynamic
family* = a static site inside `.map()`; its rendered-instance count depends on data and is **not** counted.
*Rendered instance* = an element at runtime (NOT_MEASURED). *User journey* = an operator task spanning several
controls (§D; identified, not yet traced). Excluded: test doubles, fixtures, type declarations, and `.ts` files'
non-JSX DOM manipulation (listed separately in §C.8/§C.9).
